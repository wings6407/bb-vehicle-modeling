# 悬挂、惯性与漂移烟雾

本章是可执行的制作与验收规范，**本技能附带的DMC经验未完成此套动画/粒子的原生或游戏验证**。开始前发现当前格式、动画及粒子工具；不照搬不存在的MCP名称。默认保留旧版实体，无法原生播放的交付应明确标记。

## 先记录兼容性

每次执行记录：Blockbench版本、当前format_id、可用动画/Effects/locator工具、几何与动画导出器、粒子预览能力、目标游戏/宿主版本。逐项标明可用/未验证/不支持；没有跨所有旧版宿主的默认兼容保证。按目标导出并重开代表性骨骼动画和一个有限烟雾事件后，再批量制作。游戏用交付须包含该目标下的最小可运行绑定样例与变量初始化；目标未知时先完成可审查的模型/烘焙演示，运行时绑定明确列为未交付。

## 刚体骨架

```text
rig_root                    展示路径/航向，运行时可由实体运动替代
├─ body_motion              重心附近：俯仰、侧倾、车身起伏
│  ├─ body / chassis / interior
│  ├─ door_l / door_r / hood
│  └─ steering_mount        安装倾角
│     └─ steering_wheel
├─ suspension_fl            左前轮心上下行程
│  └─ steer_fl              转向
│     ├─ spin_fl            胎体、轮毂、胎块一起滚动
│     └─ brake_fl           卡钳不滚动
├─ suspension_fr            同构
├─ suspension_rl
│  ├─ spin_rl
│  └─ smoke_rl              接地点locator，不放spin下面
└─ suspension_rr
   ├─ spin_rr
   └─ smoke_rr
```

轮拱与车壳留在body分支。车身俯仰/侧倾与轮组接地分开控制；整桥、拖拉机前桥摆动按真实机构修改，不硬套独悬。

## 反馈计算

从油门/刹车的纵向加速度、转弯横向加速度、每轮路面高度得到目标姿态。加速适度抬头，刹车点头，转弯向外侧倾；用实际世界坐标和镜像轴确认正负号。先明确单位、模型缩放和重心高度，角度及行程按车体空间限幅。

每个角度/位移自由度可用有阻尼二阶响应：

```text
x'' = omega² * (target - x) - 2*zeta*omega*x'
v += x'' * dt
x += v * dt
```

这是单位质量的弹簧阻尼响应模板。omega为弧度/秒，zeta为阻尼比；使用足够小的固定仿真步长，再采样到动画。持续输入先稳定，切换输入观察少量衰减回弹；不要把所有部件叠相同正弦称作物理悬挂。减小步长检验结果收敛，限位时处理越界速度，避免数值弹飞。

路面高度驱动轮心，车体相对于轮心产生悬挂压缩/伸展；平路上的车身侧倾不应凭空让轮胎大幅离地。用轮心、轮径和路面计算接地误差，检查车壳与轮胎的相对行程。真正可见的避震筒/连杆还要匹配两端安装点，不能只让上下两段穿离。

BB内的确定性演示可将这些响应**烘焙成数值关键帧**；真实驾驶还需要宿主提供输入、轮地检测及持续积分。交付中分别列出“烘焙反馈”“运行时驱动及变量绑定”“游戏内验证”的状态，不混称。

## 动作片段与漂移

先做起步/刹车、左右转弯、单轮压缩回弹，再组合漂移。幅度根据车型、地隙、轮拱与观看尺度调节，不把固定角度当机械参数。

漂移按入弯减速→甩尾建立滑移角→反打维持→收油/回正→悬挂衰减回弹组织。root路径切线与车身航向存在连续滑移角；仅原地摇车身不算有漂移运动。主root只处理位置和航向，惯性姿态由body_motion处理，避免两套动画重复平移。

无滑动时轮角 `theta = distance/radius * 180/pi`，单位一致，前后不同轮径分别算。后驱漂移允许后轮角速度因打滑高于地面速度；反打方向与滑移角相配，方向盘联动。镜像轮组验证本地spin/steer符号。匀速滚动用线性，连续角度保留多圈，不能只给0°/360°而忽略目标插值器的最短路径。

循环片段检查姿态、线速度、角速度和轮速接缝；非闭合路径用一次播放或明确重置，不伪装无缝循环。

## 大量烟雾

- 后轮接地点附近发射，locator跟随悬挂但不跟随spin。触发以接地、速度和后轮滑移为条件，离地/停止打滑后停发，已生成烟团继续消散。
- 发射器跟随车辆，**已生成粒子留在世界空间**。烟团逐渐膨胀、缓慢上浮、略向后散开，浅灰主体带少量深浅变化，透明度从出现到消失连续变化。
- “大量”优先通过后轮双发射点、体积、叠层与寿命形成体积感，再提高发射率；保留车身和反打前轮的辨识度。给总粒子数/透明覆盖设上限，验收低配帧率与循环后的数量。
- 可从每后轮60–100粒/秒、1–2秒寿命开始试验，数量级约为发射率×寿命×轮数，属于可调展示起点，未做性能保证。目标单位和车体缩放不同须调整粒径、初速。
- Bedrock需要粒子JSON、locator、Effects事件、client entity短名映射和实际纹理资源。有限动作关键帧用有限寿命发射器；循环上反复启动永不停止的发射器会累积。持续驾驶优先由状态进入/退出管理发射器。
- 共用图集时给烟形预留带透明轮廓的区域，设置粒子的UV子矩形和目标支持的透明混合材质；车辆实体表面只采样自身区域，分别验证车身透明排序和烟形边缘。粒子纹理路径必须指向实际交付的图集。
- 优先采样车辆同一图集中的预留烟形区或使用已获准的目标内置纹理；自定义特效图若另交，明确列出其尺寸与额外预算，不悄悄突破单图约束。不要在转动轮胎骨骼下堆几何块冒充散烟。

## 验收与完整交付

在原生时间轴检查起止、极值、中间帧及循环交界，至少包含转向+滚动、压缩+回弹、移动+持续烟雾。检查轮地接触、轮拱间隙、车壳接缝、烟团世界位置及停发后的消散；粒子数长期有界。

交付可编辑bbmodel、几何、动画JSON、粒子及纹理、client entity/控制器绑定片段，以及所需变量与单位说明。只有做过的宿主运行验证才写已通过。静态截图不能验证动作或烟雾；给预览视频/GIF及测试状态。
