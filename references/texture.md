# 单张128图集与皮肤

## 分配和复用

每个皮肤使用单张实际宽、高均≤128的颜色图集，内嵌和外部PNG一致；不要用多图、超长动画图或未说明的PBR图绕过预算。不同皮肤是可互换备选，不同时叠加加载。

先分配灯组、轮毂、格栅、标识等辨识区域，再安排大面材质和条带，最后加入少量磨损。轮组、同款座椅和适合的金属区域复用UV；文字、非对称花纹和重要阴影不盲目镜像。

共享UV不等于所有面采样整个色块。检查两个方向的像素密度、长宽比和金属纹理方向；纯色面可共用小区域。Box UV须按实际布局核查，不能把UV尺寸属性修改为128就算压缩成功。条带过长时评估沿共面处拆段或改用格式允许的逐面映射，不拉伸关键花纹。

边距从1像素开始评估，按目标过滤/mipmap验证。复制边缘色可减小串色；实际装箱、远景和斜视检查后才算容量达标。

## 材质色阶

| 材质 | 简洁表达 | 退回现象 |
|---|---|---|
| 大面积金属 | 主色+克制的亮边/暗边、少量有方向的宽色带 | 机盖中央显著黑斑、车顶强烈蓝灰块、满面噪点 |
| 橡胶 | 深灰主体、低反差胎肩/侧壁与疏朗胎纹 | 纯黑死块、太密碎纹、胎体与车身难区分 |
| 轮圈/轮辐 | 外缘亮面、侧壁中间色、内部暗层 | 只有平面亮圈、接段色差、凸起不可见 |
| 灯具 | 深色外框、中间主色、少量亮芯/反光格 | 每个灯全纯色、灯条过窄、转向/尾灯无分区 |
| 玻璃 | 统一染色、少量宽反光带，透明程度与内饰协调 | 黑板窗、反光遮满内饰、多层透明排序错误 |
| 内饰 | 仪表台、座椅主体和嵌色的清楚层次 | 极细缝线噪点、大面积无差别黑色 |

以普通光照对照图验收，光泽是颜色贴图中的材质模拟。亮色贴图不等同于PBR反射、Bloom或动态照明；目标支持的材质功能另行绑定与测试。

## 原色、风格、火焰

1. 原色：建立材质分区、灯光层次和必要识别信息。
2. 风格版：沿相同UV加入受控明暗、宽而简洁的材质色阶；不要用明显深色几何补丁代替金属质感。
3. 红橙白火焰版（用户要求时）：车身主色、火焰大形和白色强调互有主次；轮圈、玻璃染色、仪表台及座椅共同调整。保持窗洞和灯具功能清晰。
4. 新皮肤只变颜色图及相关纹理元数据。几何、UUID、Bone、UV、动画相同；逐个重开并比较固定角度。

已有大图优化可使用环境中可用的 bb-texture-optimization 技能；本技能不依赖其安装。先精确去重，再做经视觉确认的材质共享。输出报告说明实际简化了哪些信息，不宣称无损。
