# 轮廓、连接和模块

## 尺度与证据

单照片无已知尺寸时用轮径或车长归一化，只比较比例；不能把照片像素直接当毫米或米。需要与速度、重力或悬挂参数联动时，先取得一个可靠实物尺寸并记录“每模型单位对应多少米”；若使用估值则标注并保持可修改。展示烘焙可在统一模型单位内制作，但不得据此声称真实动力学标定。

## 从侧线建形

坐标可统一为 X 左右、Y 向上、车头 −Z、地面 Y=0，左右以驾驶员方向为准；使用既有工程时保留其约定并记录转换。

1. 确定轮心、轴距、轮径和车厢比例。侧上沿控制点同时约束侧板、门顶和轮眉，不拼完面板再靠浮片补断口。
2. 每段的**外侧可见边**起终点使用同一控制点。若枢轴在条带中心，旋转后还要计入半厚偏移；枢轴在外边时可直接用该边端点。两种方法不可混用。
3. 侧视 YZ 平面从 P 到 Q，条带沿本地 +Z，长度 `sqrt(dy²+dz²)`；按右手 Rx，`angle_x = -atan2(dy,dz)`。这是设计坐标的例子，须核对原生轴向及父骨骼变换。
4. 用完整父链世界矩阵比较相邻外端点，而非只看 from/to 或相加 Euler 角。模型尺度约100单位时可从误差≤0.0001单位开始；比例不同相应调整，最后仍要视觉检查。
5. 固定 A 柱下端、上端、车顶和门框端点后，再填侧板和门。门缝是明确、窄而连续的分界；A 柱弧度用少量折面，不能与门框错层。
6. C 柱外缘保持车顶到尾部的主轮廓，避免孤立凸出。后窗边界与 C 柱及顶边共用约束点，消除贯通空隙。
7. 前后脸轻微斜角按车型决定，灯组、格栅、饰条跟随同一个面板安装 Bone，避免面板倾斜而配件悬空。

曲线连续优先于增加段数；转角内侧可有少量受控交叠，但需处理重叠面、闪烁和纹理接缝。可见外侧不得断裂。旧版实体的 Cube 不承担静态旋转，旋转放在装配 Bone。

## 轮组母版

轮胎→胎肩→连续外轮圈→凹入轮毂内部/刹车盘→实体轮辐→凸起中心盖。轮圈和中心厚度必须在斜视中可见。轮胎纹理与轮辐层次在母版完成后同步复制。

外轮圈可以用规则多边形切线段：N 边、外侧对边半径 a，则每段外边长度 `s = 2*a*tan(pi/N)`。厚度 t 从外侧平面**向内**布置；每段围绕同一轮心转 `360/N`，相邻外端点闭合。轮轴沿 X 时截面在 YZ 内，段相位与轮心保持一致。相同中心的厚条随意叠加不保证外圈连续。

实心胎体可用 N/2 条旋转 cuboid，长边为外侧对边直径 D，窄边 `D*tan(pi/N)`；N 为偶数。它是重叠组合，不是布尔合并。端面重叠必须检查闪烁、覆盖顺序和材质，不能靠任意微偏移制造阶梯。

N 由观看尺度决定：从8或12边试起，确有需要再增加；不是所有车辆都用16条微小轮辐。先确认轮圈端点、凹凸、侧壁层次和像素风格，再复制四轮。前后规格不同保留同一构造法而调整参数。

右侧翻转180°会改变本地旋转轴方向，单独验证滚动和转向符号；标识、胎纹和非对称纹理不可盲目镜像。

## 细件尺度与空间

- 先做改变剪影、开口、厚度及独立运动的几何。浅接缝、螺丝、细槽和座椅缝线优先贴图。
- 沿常用观察距离看黑色腰线、小灯条和雨刷：若细到闪烁或消失，合并、加宽或贴图表达。没有所有车型共用的固定最小厚度。
- 雨刷先对齐玻璃安装面，缩短到闭合与扫动全程都在风挡范围；不从右侧或 A 柱外探出。
- 底盘用有层次的封闭体块连接地板、前后桥和动力区；消除贯通大洞，同时保留轮胎活动、轮拱及真实机械开口。
- 窗洞、货斗、座舱做实际空间；车门开启后仍有内表面和门槛。可见玻璃采用少量连续面，避免透明薄片反复叠加。

同类细节保持一个视觉尺度。灯、雨刷、门把手不应在同一车上出现极粗与发丝般细件混杂。几何数量按价值记录，DMC案例的具体Cube/Bone数不是通用质量指标。
